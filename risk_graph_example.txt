Risk Graph Example
==================

This is a text example of the risk graph structure produced by createGraph.m.
Each edge is written as:

    source -> target

Nodes
-----
RAL       Reset account lockout counter after
mPA       Minimum password age
ALD       Account Lockout Duration
MPA       Maximum password age
EPH       Enforce password history
ALT       Account Lockout Threshold
MPL       Minimum password length
PCR       Password must meet complexity requirements
SPE       Store passwords using reversible encryption
PML       Password management level
SCA       Strong customer authentication
AML       Access management level
PRM       Permissions
PR        Privilege Requirement
PRM-PR    Permissions + Privilege Requirement
NTA       Network access type
NTS       Network security type
SPI       Security Parameters Index
AV        Attack Vector
NT-AV     Network type + attack vector
AC        Attack complexity
AR        Attack requirements
AML-AC    Access management level + Attack complexity
AML-AR    Access management level + Attack requirements
EM        Exploit maturity
AL        Attack likelihood
VI        Vulnerable System Integrity
VC        Vulnerable System Confidentiality
VA        Vulnerable System Availability
OAF       Object access frequency
ISL       Information sensitivity level
OAF-VA    Object access frequency + Vulnerable System Availability
ISL-VC    Information sensitivity level + Vulnerable System Confidentiality
S         Safety
AS        Attack severity
ACSRL     Access control system risk level
OAB       Object Anomaly Behavior
OAB-AR    Object Anomaly Behavior + Attack requirements
OAB-AC    Object Anomaly Behavior + Attack complexity
OAB-AR-AC Object Anomaly Behavior + Attack requirements + Attack complexity
SAB       Subject Anomaly Behavior
UI        User Interaction
SAB-UI    Subject Anomaly Behavior + User Interaction
LOI       Level of influence, only used when LOIMethod is direct

Edges
-----
RAL -> PML
mPA -> PML
ALD -> PML
MPA -> PML
EPH -> PML
ALT -> PML
MPL -> PML
PCR -> PML
SPE -> PML
SCA -> AML
PML -> AML
PRM -> PRM-PR
PR -> PRM-PR
SPI -> PRM-PR
NTA -> NT-AV
NTS -> NT-AV
SPI -> NT-AV
AV -> NT-AV
AML -> AML-AC
AC -> AML-AC
AML -> AML-AR
AR -> AML-AR
AML-AC -> AL
AML-AR -> AL
NT-AV -> AL
PRM-PR -> AL
EM -> AL
OAF -> OAF-VA
VA -> OAF-VA
ISL -> ISL-VC
VC -> ISL-VC
VI -> AS
ISL-VC -> AS
OAF-VA -> AS
S -> AS
AL -> ACSRL
AS -> ACSRL
OAB -> OAB-AR
AR -> OAB-AR
OAB -> OAB-AC
AC -> OAB-AC
OAB-AC -> OAB-AR-AC
OAB-AR -> OAB-AR-AC
SAB -> SAB-UI
UI -> SAB-UI
SAB-UI -> AL
OAB-AR-AC -> AL

Optional direct-LOI edge
------------------------
LOI -> AS
